# CRISPR screen — input data

The count matrix and MAGeCK gene summaries below are **not distributed** with
the public repository (they are derived from restricted sequencing data) and are
git-ignored. Place them here for full local / authorised reproduction. Expected
schemas are documented so inputs can be regenerated from the upstream pipeline
in `crispr_screen/upstream/` (see also `crispr_screen/README.md`).

## `count_table.txt` (tab-separated)

MAGeCK count matrix produced by the upstream counting step
(`02_mageck_count.py` / pipeline of record).

| column | meaning |
|---|---|
| `sgRNA` | guide identifier |
| `Gene`  | target gene symbol (`INTERGENIC`/`CONTROL` for non-targeting) |
| `R0_1..R0_3` | resistant day-0 baseline, biological replicates |
| `Rpost_1..Rpost_4` | resistant tumour-derived samples (in-vivo; no TRAIL treatment in this screen) |
| `S0_1..S0_3` | sensitive day-0 baseline |
| `Spost_1..Spost_3` | sensitive tumour-derived samples (in-vivo; no TRAIL treatment in this screen) |

## `<comparison>.gene_summary.tsv` (tab-separated, MAGeCK `test` output)

One file per comparison: `Rpost_vs_R0`, `Spost_vs_Rpost`, `Spost_vs_S0`.

Standard MAGeCK gene-summary columns:
`id`, `num`, `neg|score`, `neg|p-value`, `neg|fdr`, `neg|rank`, `neg|goodsgrna`,
`neg|lfc`, `pos|score`, `pos|p-value`, `pos|fdr`, `pos|rank`, `pos|goodsgrna`,
`pos|lfc`. The negative tail tests depletion (LFC < 0); the positive tail tests
enrichment (LFC > 0).

## `gene_lists/*.txt`

Plain gene-symbol lists (one per line) used as enrichment inputs. These contain
gene symbols only (no per-patient or raw-count data) and **are** committed.
Provenance: `gene_lists/PROVENANCE.txt` (generated by `00_derive_gene_lists.R`
at nominal p < 0.05).
